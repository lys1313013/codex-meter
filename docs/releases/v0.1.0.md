发布日期：2026-10-28。

- 原生 SwiftUI / AppKit 界面，可拖动、置顶并调整大小、配色。
- 按服务返回的额度分组和窗口展示剩余比例、重置倒计时。

### 安装与已知限制

- 安装包：`Codex-Meter-0.1.0-macos-arm64-adhoc.zip`，附同名 `.sha256` 校验文件。Release 附件不受 Actions 临时制品的 14 天保留设置影响。
- 本次构建资产为 Apple Silicon（arm64），最低系统声明为 macOS 13；旧系统和 Intel 尚未完成实机验证。
- 需要已使用 ChatGPT 账号登录的本机 Codex；API Key 登录不提供这里展示的订阅额度。
- ZIP 安装包免费，安装和使用无需购买 Apple 开发者会员。此包采用 ad-hoc 临时签名，未经 Developer ID 签名和 Apple 公证；首次打开可能需要手动允许。
- 界面目前为中文；Codex 接口变化可能需要后续适配。

### 首次安装

1. 在本 Release 的 Assets 中下载 `Codex-Meter-0.1.0-macos-arm64-adhoc.zip` 和 `Codex-Meter-0.1.0-macos-arm64-adhoc.zip.sha256`，放在同一目录。`Source code` 是源码压缩包，不是应用安装包。
2. 在终端进入下载目录，运行下面的命令，确认显示 `OK`：

   ```bash
   shasum -a 256 -c Codex-Meter-0.1.0-macos-arm64-adhoc.zip.sha256
   ```

3. 双击 ZIP 解压，将 `Codex Meter.app` 拖入「应用程序」（Applications），然后从那里打开。

### 提示「Apple 无法验证」时

对于从本仓库 Release 下载并校验通过的安装包：

1. 在「未打开 Codex Meter」或「Apple 无法验证」提示中点击「完成」（或关闭提示）。
2. 打开「系统设置」→「隐私与安全性」，向下滚动到「安全性」，找到 Codex Meter 被阻止的提示。
3. 点击「仍要打开」（`Open Anyway`），在后续提示中确认「打开」，并按要求使用密码或 Touch ID 授权。
4. macOS 会为该应用保存例外，之后通常可以直接打开。

如果没有看到「仍要打开」，先从「应用程序」再次尝试打开该应用，再返回「隐私与安全性」查看。按钮名称可能随 macOS 版本略有差异，参见 [Apple 官方打开步骤](https://support.apple.com/zh-cn/102445)。
